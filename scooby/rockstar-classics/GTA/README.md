# GTA downloads

Each game owns its editions: SA/Classic, SA/Definitive-Edition, Vice-City/Classic, Vice-City/Definitive-Edition, III/Classic, III/Definitive-Edition, and IV.

SA/release.json identifies the current release. Current SA downloads contain the authenticated DLL, fonts, languages and required notices. Loading support is built into Scooby Loader; there is no separate helper executable in new game packages.

Older SA release paths remain immutable for existing loader versions. They are compatibility artifacts, not the current download. Dashboard and loader implementation source belongs in the native loader repository under src/games/<game>, never in this public downloads repository.
