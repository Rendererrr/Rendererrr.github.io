3. Import your content

In Scooby, open Addons/Replacements, choose a category and use Import Folder. Select a model and press Spawn to load its pack automatically. Read the extracted README for sound and animation instructions.

Use the matching edition folder. Moving Legacy files into an Enhanced folder does not convert them. Use Settings > Converter in Enhanced with a current Scooby build containing the R8 converter repair. Unsupported formats stop conversion and keep the originals.
