Scooby GTA V Addons - Legacy and Enhanced

Extract the ZIP to a folder of your choice. It contains source packs, loose
resources, original instructions and credits. Import the content you want from
Addons/Replacements in Scooby; downloading this ZIP does not mount any pack.

Vehicles: choose a pack inside addons/vehicles/Legacy or Enhanced. In Enhanced,
use Settings > Converter for supported Legacy packs. Moving a folder between
editions does not convert its resources. The corrected r820_enhanced example is
already converted; its Legacy original is also included.

Peds: import the loose ped folder and let Scooby prepare its DLC. A full game
metadata pool can prevent new ped packs loading; conversion does not expand it.

Animations: import the Fortnite-Dances/content folder, then use Animations.
Sounds: retain the complete original containers and choose one alternative for
each provider. Do not mount competing sound packs together.

Replacements: the original weapon/ped/vehicle resources are included. Use only
replacement actions supported by your Scooby build. Source presence does not
mean every resource supports live replacement or restoration.

Use a current Scooby build containing the R8 render-target conversion fix.
Supported compressed colour render targets are rebuilt with their pixels and
names preserved; unsupported formats stop conversion and preserve the original.
Read the in-menu Settings > Guide for import and spawn instructions.

Do not replace files while their pack is mounted. Keep the original downloads.
Original author instructions, filenames and credits have been retained.
