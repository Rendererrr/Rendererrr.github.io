# VFX engine assets

These skies and particle definitions are original procedural assets generated by
`tools/build_vfx_assets.py`. No Valve textures, models, sounds or compiled shaders
are included. The sky materials use the game's installed `sky.vfx` shader.

- Scooby Aurora: teal curtains, violet glow and stars.
- Scooby Copper Dusk: warm horizon with a violet zenith.
- Scooby Deep Space: violet star field and a soft galactic band.
- Scooby Rose Dawn, Ion Nebula and Storm Bank: original procedural cloud skies.
- Eight original chams textures, with PNG sources under `source-images/`.
- Rain, snow, storm, ash, embers, dust, leaves, fireflies, motes and petals: native world-space particles
  using an original soft sprite and dedicated origin, RGB and opacity controls.

`manifest.json` covers all installable resources. `source/*.json` and the generator
make the particle definitions and texture construction reviewable and reproducible.
Install only the manifest files under `game/csgo/materials/scooby_vfx` and
`game/csgo/particles/scooby_vfx` using the accompanying verified installer.

These assets follow this project's license. Resource-format references are linked
in docs/VFX_ENGINE.md; the resource writer is an independent implementation.

The media extension ships 31 compiled resources. `preview.png` is a source-art
contact sheet. `source-images/` contains eleven PNG originals for editing and
reimporting; these images are not copied into game folders by the installer.
See docs/VFX_MEDIA.md for PNG/GIF import and profile portability.
